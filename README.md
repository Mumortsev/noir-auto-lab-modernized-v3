# NOIR AUTO LAB — Demo Showcase

Демонстрационный статический сайт премиальной детейлинг-студии.

- Без сервера, форм с реальной передачей данных, сторонних API и трекеров.
- CSS Aurora Glow автоматически облегчён на мобильных и слабых устройствах; при `prefers-reduced-motion` сохраняется статичное свечение.
- Генеративные иллюстрации автомобилей (вырезанные из созданных специально для NOIR концепций). Все примеры работ и отзывы явно обозначены как демонстрационные.
- Конфигуратор, ползунок сравнения, карусели, три темы, печатный демо-расчёт.
- Для GitHub Pages: `Settings → Pages → Build and deployment → Deploy from a branch → main / (root)`.
- Из-за политики GitHub Free репозиторий должен быть публичным для Pages, если нет платного плана с поддержкой приватных репозиториев.
- Путь публикации: `https://mumortsev.github.io/demo-noir-auto-lab/` только после переименования репозитория и включения Pages.

Копирование реальных данных/персональных контактов не выполняется.
